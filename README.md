# 坦克大战 · Tank Battle

一个用原生 HTML5 Canvas + JavaScript 编写的经典坦克大战（Battle City 风格）网页游戏。单文件实现，零依赖，打开 `index.html` 即可游玩，也支持一键部署到 GitHub Pages。

## 玩法

- 控制己方坦克，**消灭全部敌军**即可过关（每关 20 辆敌军，共 3 关）。
- 保护屏幕底部的**金色盾牌基地**——基地被敌军击毁则游戏结束。
- 可摧毁**砖墙**，**钢墙**无法击穿，子弹可越过**水面**，坦克会躲进**树丛**里。

## 操作

| 按键 | 动作 |
| --- | --- |
| `W` `A` `S` `D` / `↑` `←` `↓` `→` | 移动 |
| `空格` / `J` | 射击 |
| `回车` | 开始 / 重新开始 |

## 敌军类型

| 颜色 | 类型 | 速度 | 生命 | 分值 |
| --- | --- | --- | --- | --- |
| 灰 | 普通 | 中 | 1 | 100 |
| 红 | 快速 | 快 | 1 | 200 |
| 绿 | 装甲 | 慢 | 2 | 300 |

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖或构建工具。

## 部署到 GitHub Pages

1. 在仓库 **Settings → Pages** 中，将 Source 设置为 `Deploy from a branch`，分支选择 `main`（或 `master`），目录选择 `/ (root)`。
2. 保存后等待部署完成，即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。
